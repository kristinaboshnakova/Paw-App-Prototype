# Pawly — pet care web app (prototype)

Отвори `index.html` в браузъра или публикувай цялата папка на GitHub Pages.

## Страници
- index.html — регистрация / вход
- dashboard.html — приветствие и преглед
- water.html — вода
- food.html — храна
- train.html — тренировки
- walkings.html — разходки и GPS (ако браузърът поддържа)

## Важно за сигурността
Това е frontend прототип. Профилите и паролите се съхраняват в localStorage **без криптиране и без реална автентикация**. Използвай само тестови данни и НИКОГА реални пароли. Преди публично пускане: интегрирай Supabase Auth и база с Row Level Security.

## GPS
При активна сесия GPS може да измерва приблизително изминатите километри. Изисква HTTPS/localhost, разрешение от потребителя и подходящо устройство. Таймерът не е устойчив на презареждане на страницата; маршрутът не се съхранява. Картата е илюстративна.

## Файлове
`assets/css/style.css` — дизайн; `assets/js/app.js` — всички интеракции.
